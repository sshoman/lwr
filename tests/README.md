# Experiment index

## Test 001: refutation and transfer

Folder: `test_001_refutation_transfer/`

Question: can a general LLM propose conditional claims from observed outcomes, select tests that try to break those claims, and pass only validated claims to a new agent that no longer has access to the source episodes?

Status: pilot implementation. Use the single PowerShell command in the root README. The test's source files are packaged in its folder as `source_bundle.zip` and unpacked automatically by the launcher.

Future experiments get their own numbered directory. They must not reuse Test 001's data or results as if they were independent evidence.
